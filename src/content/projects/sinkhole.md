Sinkhole is a browser-based DOM XSS detection extension designed to identify potentially dangerous client-side data flows and JavaScript sinks. It helps security researchers inspect web applications for DOM-based cross-site scripting vulnerabilities directly from the browser.

## What it does
- Monitors client-side JavaScript behavior for potentially dangerous DOM XSS sinks.
- Helps identify suspicious data flows from attacker-controlled sources to sensitive JavaScript sinks.
- Provides security researchers with a lightweight browser-based workflow for DOM XSS testing.

## Highlights
- Built specifically for practical web application security testing.
- Makes DOM XSS investigation faster directly from the browser.
- Useful for researchers analyzing modern JavaScript-heavy applications.
- Designed to support repeatable client-side security testing workflows.
