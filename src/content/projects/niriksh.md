Niriksh is an ML-based network intrusion detection system designed to analyze network traffic and identify potentially malicious or anomalous activity. It combines network traffic analysis with machine learning to assist security teams in detecting suspicious network behavior.

## What it does
- Analyzes network traffic and extracts relevant features for security monitoring.
- Uses machine learning to classify potentially malicious network activity.
- Helps identify suspicious patterns such as scanning, anomalous traffic, and network-based attacks.

## Highlights
- Combines network security monitoring with machine learning-based detection.
- Designed for practical SOC and network security workflows.
- Provides a foundation for analyzing network behavior and generating security alerts.
- Built to support experimentation, testing, and security research in controlled environments.
